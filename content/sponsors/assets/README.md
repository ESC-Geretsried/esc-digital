# Sponsor assets

Verified sponsor logo files belong here.

Requirements:

- preserve the original supplied/approved logo where technically reasonable;
- use a stable filename tied to the sponsor `id`;
- record the repository-relative asset path in `../sponsors.json`;
- do not invent or redraw missing logos;
- do not hotlink logos from sponsor websites at runtime;
- once accepted into this directory, Git is the canonical tenant copy and recovery source.
