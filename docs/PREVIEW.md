# ESC Digital preview

GitHub Pages is a temporary visual review surface for M2. It is not PROD and is not the canonical hosting architecture.

Canonical builds default to `/` so the site remains suitable for a future custom domain or another static host. The GitHub Pages workflow overrides the Hugo base URL only for the repository preview path `https://esc-geretsried.github.io/esc-digital/`.

`www`, `esc-geretsried.de`, PROD DNS and the frozen design reference are outside this preview deployment.
