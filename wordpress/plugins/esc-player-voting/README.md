# ESC Spieler des Spiels

Installierbarer Quellstand des ESC-Plugins für das 18-Minuten-Spielervoting.

## Releases

Alle vorhandenen versionierten Plugin-Stände liegen unter `releases/`.
Die Datei `esc-player-voting-0.1.0-rollback.zip` ist die Rückfallversion.

Der Ordner `source/` enthält den aktuellen Quellstand.
